# /src Documentation

## /finger

This folder contains the header file and cpp file for the finger object. This object has the properties and methods needed for each finger to be driven, interpret hall effect readings, and execute PID.

## /stepper

This folder is no longer used

## constants.h
This header file is where all of the pin assignments are made. Also, this is where all of the finger instances are created. 


## functions.h
This header file includes all of the control functions that were not methods of the finger class. This includes User Interface functions and IR detection.
